# Naskah cepat 30–60 detik

- **Panjang:** 90–160 kata (±3 kata/dtk di ElevenLabs) → 30–55 dtk. Jangan lewat 170 kata.
- **Rumus beat** (gaya cerita fakta seperti `REFFERENCES/`):
  1. **Hook (≤ 2 dtk):** fakta paling absurd dalam satu kalimat pendek.
  2. **Setting (1 kalimat):** tahun, tempat, siapa.
  3. **Aksi:** 2–3 eskalasi, tiap 5–8 dtk ada kejutan kecil.
  4. **Snap/twist:** momen paling gila.
  5. **Deadpan/penjelasan:** satu ide lewat analogi sehari-hari.
  6. **Callback penutup:** kembali ke hook, lalu kalimat penutup khas bible.
- Kalimat pendek, bahasa lisan, sapaan dari bible. Angka ditulis seperti diucapkan ("seribu delapan ratus delapan puluh sembilan").
- Jangan menjelaskan apa yang sudah terlihat di layar. Setiap kalimat harus bisa digambar.
- Hanya fakta LOLOS/REVISI, dengan redaksi aman dari `03-cek-fakta.md`. Janji di hook harus dibayar lunas di isi.
- Hook tidak boleh ada di `ledger.md`. Sisipkan komentar khas narator agar tidak terasa template.
- Tandai `...` untuk jeda dan **tebal** untuk penekanan. TEMPERANCE memakainya untuk prompt ElevenLabs.

## Output `04-naskah.md`
```
## Variasi hook  A) … B) … C) …   Rekomendasi: X karena …
## Naskah lengkap   [HOOK] … [SETTING] … [AKSI] … [TWIST] … [PENUTUP] …
## Statistik   kata · perkiraan durasi (kata ÷ 3) · karakter (untuk kuota ElevenLabs)
## Judul kerja (3 opsi)
```
Setelah Gerbang 1, tulis `Status: FINAL (hook X)` di baris atas.

Aturan bersama: bible channel menang bila bertentangan. Kerjakan versi terkecil yang tuntas, lapor singkat (sekali baca), dan sebut apa yang dilewati atau belum dicek.
