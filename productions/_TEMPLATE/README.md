# Template folder produksi

LUCIFER menyalin `status.md` ini ke `productions/<ID-VIDEO>/`. Peta lengkap ada di [[HOME]].

```
<ID-VIDEO>/
├─ status.md                ← dipantau LUCIFER & Istana
├─ 00-brief.md … 12-publish.md
├─ audio/                   ← vo.mp3 (dari Tuan), words.json, mix.wav, sfx/ (TEMPERANCE)
├─ footage/raw|clips/       ← GREED
├─ render/                  ← KINDNESS
└─ export/                  ← <ID>_master.mp4, <ID>_cover.jpg, check/, qa.json (SLOTH, WRATH)
```

ID: `<channel>_<YYYYMMDD>_<NN>_<slug>`, contoh `ch01_20261126_01_semut-tidak-tidur`.
Produksi `ch01_20261125_01_demo` memakai penomoran file lama (05-storyboard … 13-publish).
